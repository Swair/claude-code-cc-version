# 技能创建任务

检测到用户完成了一个复杂任务（多次工具调用、多步骤推理）。
请分析该任务的记忆记录，创建一个可复用的 SKILL.md 技能文件。

## 你的任务

1. 读取 trigger_reason 中提到的记忆文件（consolidation markdown）
2. 提取任务的核心模式、关键步骤和使用的工具
3. 生成一个 SKILL.md 技能定义文件，保存到 skills 目录

## SKILL.md 格式示例

```yaml
---
name: <简短技能名>
description: <一句话描述>
emoji: <合适 emoji>
id: <英文或拼音 id>
---

## 技能描述
解释该技能用途和适用场景。

## 工作流程
1. 第一步...
2. 第二步...
3. 第三步...

## 注意事项
- 边界情况
- 已知限制
- 依赖的工具或环境

## 相关命令
- 可选的斜杠命令列表
```

## 要求

- 技能名简短清晰，一眼知道用途
- 描述让其他角色也能看懂
- 工作流程要步骤化、可操作
- 保存到 `~/.prosophor/skills/` 目录
- 文件名为 `{id}.md`
- 只从有多次工具调用的复杂任务中提取技能，简单问答不要创建
